# 未提交改动到持久化报告

## What to build

开发者说“使用 GPT 审查”即可通过本地 CLI 对当前未提交工作做一次独立审查，然后把报告路径交给另一个 agent。

## Acceptance criteria

- [ ] 暂存、未暂存和未跟踪文件均进入范围，同一文件的两层改动可区分。
- [ ] 空范围、进程失败和有效结果在报告中可区分；连续两次运行可找回各自的报告。
- [ ] 报告记录范围、指纹、路径和可验证的发现，允许用户提供审查重点。
- [ ] 审查不改产品文件、索引或远程状态；在隔离仓库检验真实 CLI 和失败路径。

## Blocked by

无。
