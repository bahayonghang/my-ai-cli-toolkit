# web-research

跨平台互联网**来源发现与本地归档**的工作流 skill。把「我想要的东西在网上」变成
「我确认过的来源已经在本地」。

## 定位

| 需求                                 | 用哪个                     |
| ------------------------------------ | -------------------------- |
| 找到、核验、落盘具体来源             | `web-research`（本 skill） |
| 主题调研、横向对比、带引用的研究报告 | `deep-research-pro`        |

两者互补，不重叠：`deep-research-pro` 产出结论性综述且不落盘产物；本 skill 产出可核验的
候选清单与本地文件，不产出综述。需要综述时，本 skill 交出候选清单后转过去。

## 流程

```text
锁定目标 → 发现 → 核验 → 候选清单（停止） → 用户确认 → 归档
```

阶段之间是硬边界。最关键的一条：**搜索结果绝不自动转下载**——归档需要独立、明确的当轮请求。

## 依赖

只依赖当前环境真实可用的能力，全部按可得性降级，不可用时报缺口而非自动安装：

| 能力                 | 用途                   | 必需 |
| -------------------- | ---------------------- | ---- |
| `WebSearch`          | 通用公开网页检索       | 是   |
| `WebFetch`           | 候选核验、正文归档     | 是   |
| 搜索类 MCP（如 Exa） | 语义化检索、批量取正文 | 否   |
| `gh` 等平台原生 CLI  | 结构化公开检索         | 否   |
| `yt-dlp` 等下载工具  | 媒体归档               | 否   |

无 bundled scripts。这是 advisory/工作流形态的 skill，`skills/development-workflows/AGENTS.md`
明确认可该形态。

## 安全边界

7 条硬约束写在 `SKILL.md` 的「安全边界」一节，摘要：

- 所有平台只读，不改变任何账号状态，不操控客户端 UI
- 搜索不自动转下载
- 登录态与私人数据需当轮明确授权，且授权不可转移到下载
- 匿名公开路线优先，不绕过验证码、登录墙、付费墙、限流或地区限制
- 不打印或保存 Cookie / Token / API Key / 敏感 URL 参数
- 不覆盖既有产物，不自动删除；清理只入回收站
- 付费或大批量操作先报范围与预计数量

## 校验

从仓库根目录：

```bash
just skills-check      # frontmatter 校验（硬门）
just ci                # 完整本地 CI
```

`evals/evals.json` 是评审与未来工具资产，CI 不执行它（见 `skills/development-workflows/AGENTS.md`）。
它锁定路由边界：正向触发、以及两个 routing-negative 用例（主题调研应转 `deep-research-pro`、
未经确认不得下载）。
