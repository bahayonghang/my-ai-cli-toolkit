# Resume Writing（简历结构与定制规则）

W1 简历分支与 W2 定向修改共用。事实来源：三事实源联合（profile ∪ master-cv ∪ behavioral）；历史定制稿只作措辞参考不作事实来源。

## 逐节定制

### Profile Statement（最重要的一节）
紧跟姓名联系方式之后，5-7 行"电梯陈述"：为什么你胜任**这个**职位，雇主雇你会得到什么。跨域求职时，把"领域迁移论证"（背景如何连接对方的问题）放在开头第一二句——这是转行者最强的牌，先打。

### 核心技能
- 按岗位重排与强调；5-7 条 bullet，每条带一句它如何为该职位创造价值
- JD 的原词在真实适用时优先于同义词（含小节标题）：招 "MLOps" 的岗就该看到 "MLOps"，不是 "ML Deployment"

### 教育
- 最高学历必列；资深岗位从简（年份+头衔即可）
- **在读学历必须显式标注**：条目内写明 "在读，预计 YYYY-MM 完成"。裸年份区间会被读者当作已完结学历——这是在背调环节才被发现的事实性错误。在读认证、课程同理
- 一致性检查：profile statement、教育条目、可入职时间三处的完成日期必须一致

### 工作经历
- 最近一段 4-6 条 bullet，前一段 3-4，更早 2-3
- 尽可能量化："处理时间降低 X%"、"方案被团队采纳"

#### Tenure vs 可见产出检查
定稿前用陌生人视角看每段经历：**时间跨度 vs 展示的工作量**。两年经历只有一条项目会读成低产出——不管是否公平。三类高危：转行（部分时间在学习）、长周期工作（一次交付以季度计）、长期绑定单一客户/产品的岗位。

三个诚实修复，按优先级：
1. **挖出更多真实工作**：次要项目、内部工具、支持性工作，常因"觉得不重要"而没上简历
2. **显式分期**：初期熟悉领域/支援团队 → 后期主导某项工作直至交付；分期弧线读作成长曲线
3. **解释长周期原因**：现场数据采集、领域专家验证、真实产出的部署迭代——懂行的审阅者立即接受

**禁止**：编造项目补白；悄悄缩短在职日期美化比例。两者都会在背调中暴露，且比观感问题严重得多。若修复后仍会被问，把答案写进面试准备（这段时间实际在做什么 + 结果是什么），不要临场即兴。

### 职业空窗期
如实、简短说明；写清期间的专业发展；定位为主动的技能重建与方向调整。

### 发表 / 获奖 / 证明人
- 发表选 3-4 篇最相关的，附 Scholar 链接；非学术岗从简
- 证明人 2-4 位（姓名、职务、公司、联系方式），结尾 "More references available upon request."；**不附推荐信原件**——雇主通常直接联系证明人

### 证据链接
简历里每个可验证的产物（公开项目、获奖作品、论文）都带上链接。最强主张可一键验证的简历，让其余所有主张也更可信。

## Relevance-Weighted Cutting（超页裁剪）

内容超出页数上限时，不按"最老的先删"，给每条候选行打分：

> **(a) 与本 JD 关键词和职责的相关度 × (b) 该内容的唯一性（是否他处重复）× (c) 叙事依赖（求职信是否引用了它）**

总分最低的先删。旧岗位但命中 JD 关键词的 bullet，价值高于新岗位但不命中的。禁止压缩几何边距或行距凑页数。

## 关键词覆盖表（ATS 与诚实双用途）

对照 W1 提取的 required/preferred 关键词清单逐个核对：

| 状态 | 处理 |
|---|---|
| covered | 完成 |
| synonym-only | 概念已在但用了别的词：JD 原词真实适用则改用原词 |
| missing (have it) | 档案显示确实具备但简历没写 → 自然位置补写（优先经历 bullet 而非 profile statement）|
| missing (gap) | 真缺口 → 保持缺失，求职信中桥接。**永不 stuffing** |

跨语言情形：JD 语言与 CV 语言不同时，CV 用自己语言合法覆盖的概念记 synonym-only 并注明语言差异。

## 定稿清单

- [ ] 每条 claim 可溯源到三事实源之一；日期、职衔、数字零漂移
- [ ] profile statement 针对该岗位定制，非通用模板
- [ ] required/preferred 关键词覆盖表已出且四态分明
- [ ] 在读学历已标注；tenure-vs-output 已过目；无编造、无日期篡改
- [ ] 页数符合上限（见 pdf-pipeline.md）；编译目检通过（有 TeX 环境）
- [ ] 小节标题语言与正文一致（多语言时标题也要翻译）
