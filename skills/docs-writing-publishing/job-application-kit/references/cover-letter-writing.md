# Cover Letter Writing（求职信规则）

W1 求职信分支。语言默认跟随 JD 语言（与简历的固定语言策略不同：信件逐岗匹配 JD 语言）。

## 结构

1. **开头段**：职位名 + 为什么写这封信（1 句）；立刻把背景连到岗位（1-2 句）；必须针对这家公司定制，禁用模板开场。
2. **动机段（紧跟开头，前置）**：为什么是**这家**公司——引用其使命、价值观、市场位置的具体信息；讲你将贡献什么，不是你能获得什么；若与公司有人聊过，自然引用那次谈话。
3. **主体段（任务解决导向）**：最相关的经验先行，围绕"他们的哪些任务你能解决、怎么解决"；3-5 条 bullet 列具体技能/成就，每条具体且结果导向；至少一条体现主动性。
4. **收尾**：简短、自信、向前看。"期待您的回复"级别即可，不乞求、不过度热情。

## 称呼

- 知道 hiring manager 姓名 → "Dear <First Last>,"
- 知道团队 → "Dear <Company> hiring team,"
- 都不知道 → "Dear Hiring Manager"（或 JD 语言等价说法）。避免 "To whom it may concern"

## 篇幅——硬性一页

- 含签名块在内恰好 1 页；正文预算 **250-300 词**（350 必溢出）
- 结构按三块计（开头 + bullet 段 + 收尾），第 4 块仅在其他块短时使用
- 增加公司特定内容时同步裁剪其他内容，不加净长度
- 超页裁剪用 relevance-weighted cutting（resume-writing.md）：先删复述 bullet 的句子，再删不命中关键词的 bullet，命中关键词的最后动

## 内容纪律

- Forward-looking framing 优先（writing-style.md）：解决任务而非复读 CV
- 每个 claim 有具体支撑；公司主张先核实
- 缺口诚实桥接："X 尚未在我的日常工具箱里，但它是 Y 的自然延伸"
- JD 提到的后勤事项在信中回应：安全审查意愿、可入职时间、地点契合、reference/job ID
- 全文风格规则（无破折号/无陈词滥调/主动语态）与语气校准同 writing-style.md

## 定稿清单

- [ ] 无 em-dash、无陈词滥调、无空洞填充
- [ ] 每个主张有具体例子；前瞻框架成立
- [ ] 动机段引用该公司真实使命/项目（已核实）
- [ ] 公司名与职位全文正确；日期正确
- [ ] 恰好一页；称呼得体；语言与 JD 一致
- [ ] 标题/主题行具体而非通用
