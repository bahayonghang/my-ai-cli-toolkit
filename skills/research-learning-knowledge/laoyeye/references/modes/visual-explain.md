# 大图少字的视觉讲解

只在用户要图解、直观页面或 HTML 讲解时使用。纯文本解释用双层解释；此方法不承担生产 UI / 网站实施。

输入为概念、受众、要看懂的关系和用户给定目标路径。明确可用文件与展示工具；若需保存而路径未定，按现场规则选择专用 artifact 位置或只补问位置，不静默改软件项目。

1. 选一个核心关系，用大图、空间位置、箭头或状态变化呈现；一屏聚焦一个意思，文字只保留理解必要的标签和说明。
2. 产出可打开的 HTML artifact，优先自包含 HTML / CSS / SVG；需要交互时用最少脚本，不依赖外部 CDN、账号或未经允许的上传。
3. 用实际工具打开并检查可读性、图与文字对应、关键交互和错误状态。没能打开则报告“未做视觉验证”，不把代码存在称为看过效果。
4. 交付真实文件链接、阅读方式、图的局限和一项理解检查；例子数据标为示意。

不支持文件写入时可交付 HTML 文本并注明未保存；不声称已生成可下载文件。目标关系讲清即停止，不把教学 artifact 扩成完整产品，不擅自安装框架或服务。
