# 最小可逆实验

用于缺少证据而争论无法收束的决定。输入是目标、待选方向、可用资源和不可接受损失。设计实验不等于授权运行实验；不自动报名、付款、发消息、部署或改生产。

1. 列出三个可被反证的核心假设，分别说明为什么影响决定；按“结论敏感度 × 未知程度”选其中一个关键假设，不同时测全部。
2. 默认七天，用户给周期则优先。设计最少投入、可退出、能观察真实行为的验证；明确对象、步骤、资源、负责人和退出 / 恢复方法。
3. 设指标、取样方式、基线以及继续 / 停止阈值；阈值在见结果前固定，避免换指标找成功。无数据的数字标为待校准假设，不装成行业基准。
4. 写结果解释：达到阈值如何继续、未达到如何停止、无结论如何减少噪声；区分验证无效与假设被否定。
5. 给今天可做的第一步、预计成本和复盘时间。交付后停止，用户另行授权才进入执行。

输出三假设、选择理由、实验卡、指标与阈值、资源和第一步。风险无法压到可逆范围就缩小或停止设计；不以“一周实验”为由替用户承担重大不可逆后果。
