# 第一性原理重建

用于用户希望摆脱习惯方案，从目标和底层约束重新推导。若要攻击一个已成形方案，选对抗审查；不要把一切任务强行归零。

输入：要实现的结果、当前做法、硬约束及已知证据。

1. 分表列可验证事实、未验证假设、目标与约束。区分真正不可变的限制与只是沿用的做法；说明判定依据，不把偏好说成物理定律。
2. 找出当前方案依赖的关键假设，问“去掉它，目标仍能怎样实现”。把问题拆到可以核验或明确承认未知的组成关系。
3. 从这些关系重建少量可行路径，逐条检查资源、风险、约束和失败条件；不得用空洞“从本质出发”替代推导。
4. 与旧方案用同一目标和指标比较：改善什么、牺牲什么、哪些前提仍待检验。
5. 给最小验证第一步和会使方案被放弃的结果。若事实支撑旧方案更好，直接保留它。

输出事实 / 假设表、推导链、候选路径、对照和验证。事实无法取得时停在条件模型，标明缺口；验证方案不等于授权运行，不扩成没有必要的全面重构。
