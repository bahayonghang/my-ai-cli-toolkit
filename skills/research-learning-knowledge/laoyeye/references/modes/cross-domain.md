# 跨领域借鉴

用于本领域常规办法受限，想寻找远处可迁移机制。输入是难题、目标、约束和已经试过的做法。

1. 先去掉行业术语，写底层结构：参与者、资源、反馈、时延、瓶颈、激励或信息差。结构说不清就补一个关键问题。
2. 找至少三个相距较远领域的同构案例。每例写“原领域如何解决 → 对应本问题哪一关系”，不能只列名人故事或相似外观。
3. 真实案例给可追溯来源；无法核实就标待核实，或明确改为虚构示例，不能把故事当历史证据。
4. 分析可迁移前提、环境差异、成本和失效条件。机制在原领域有效不保证此处有效。
5. 从候选中推荐一个低成本、可逆实验，写预期观察和否定标准。

输出抽象模型、三个案例映射、迁移 / 失效条件和实验建议。用户只要灵感可短交付，但不省略真假标记。没有足够案例就如实给缺口，不编满数量；实验由用户决定是否执行，完成分析即停。
