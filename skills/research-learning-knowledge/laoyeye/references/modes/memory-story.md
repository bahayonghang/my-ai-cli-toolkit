# 异域故事助记

用于用户给一个领域，希望挑选值得记住的概念并用故事建立记忆线索；不要求先有一次解释失败。

1. 从指定领域选一个有深度、约研究生层次的概念，依据已有水平调节前置知识；说明选取理由时先不泄露故事的谜底。没有领域才问领域。
2. 在不同于该学科的世界写原创寓言。故事围绕概念的关键结构展开，用冲突、约束和结果制造记忆钩子，开头不报概念名称，末段才揭示。
3. 故事后给准确解释，将主要隐喻逐项映回术语，并标明哪些情节只是助记、哪些对应真正机制。
4. 给一个短的回忆线索和一个新情境，让用户尝试从故事取回概念。不能把好记当成证明，更不把一段故事代替完整理论。

输出概念选择、故事、隐喻映射与回忆提示。用户已经指定概念就尊重，不擅换题；用户要浅显版本则降难度。材料不足或不确定时声明，不虚构真实研究。完成一概念即停，不批量铺成术语百科。
