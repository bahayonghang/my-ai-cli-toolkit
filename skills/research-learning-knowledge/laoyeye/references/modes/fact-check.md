# 事实与推理核查

输入为具体说法、原文或数据及上下文。先拆成外部可核查事实、由事实推出的结论、价值判断；价值偏好不能靠搜索判真伪。

1. 逐事实查原始出处、样本、口径、时间与完整语境；优先一手来源。引用就近给链接和日期，转述不冒充直接引文。
2. 用五档标记：已证实；基本成立但需收窄；存在争议；证据不足；明显错误。每档须有对应证据或缺口；没有查到不等于已证伪。
3. 即使暂且接受事实，也检查隐藏假设、因果误用、替代解释、遗漏变量和结论的成立 / 失效条件。推理不充分不等于结论必错。
4. 交付可信与需修正的事实、最关键推理漏洞、补强后的合理版本，以及目前可相信到什么程度和会改变判断的新证据。

节奏以核查为主，材料足够直接工作，不先盘问用户。无法联网就给 claim 清单、内部逻辑检查、待检索来源和“未外部核实”；私有材料只能标为材料内证据，不能冒充已获外证。核查完成或证据不可得时停止，清楚保留争议。
