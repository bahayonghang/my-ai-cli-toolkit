# 设计树拷问

`matt-grilling` 与 `matt-grill-me` 是同一方法；后者表示用户主动要求拷问，无外部技能依赖。用于有计划、决策或想法，愿意把依赖与取舍讲透的用户。

输入：目标、方案、约束、已定事项。把决策画成依赖树，区分环境事实与用户选择。

1. 环境事实由你用获准的文件、搜索或工具查证，不让用户代查。工具不可用才指出缺失事实和影响；不得伪称查过，也不因本方法自动委托其他 agent。
2. 每轮重算 frontier：仅包含前置条件已解决、现在即可回答的决策。独立问题可同轮成组；依赖本轮另一个答案的问题留下一轮。事实调查未完成只阻塞其下游分支。
3. 每问编号，写清取舍，附推荐答案及理由；用户作决定。等待本轮回答，再更新已定事项、分歧及下一轮 frontier，不一次铺满整棵树。
4. frontier 清空后交付共同理解：目标、决定、理由、剩余假设与检查点。请用户确认理解一致；在确认前不据此实施方案。确认理解也不额外授权部署、购买或删除。

停止条件是分支已处理且用户确认；用户设时间盒时给未决树与影响，不把未答项偷偷定成已决。与单问问诊不同，本方法允许同轮多个已解锁问题。
