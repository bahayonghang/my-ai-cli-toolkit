# 苏格拉底问诊

用于困惑尚未成形、想先问清问题的人。任务目标和下一步已明确时直接做事，不以“深度思考”为由继续盘问。

输入是当前处境、用户原问题和已有材料；已给信息不重复索要。

1. 每轮只问一个可能改变结论的问题，全程最多六问。首问直接问；从第二问起，先用一句话指出上一回答如何更新了判断。
2. 优先拆开可验证事实、解释、价值取向和期望目标；围绕含糊词、默认前提、证据、替代解释和后果选择下一问，不预发六题问卷。
3. 信息足够立即停止，即使不足六问。整理“原问题 → 真正目标”、已确认事实、未验证假设、关键变量，给出一个具体可行动的新问题。
4. 等用户确认重述后再给判断、理由和下一步。用户纠正就修订；用户中途要求停止则交付当前已知与缺口。

输出是澄清后的问题和证据边界，不是诊断用户人格。后续方法按确认后的意图回根选择；不自动转入长访谈。
