# 两边最强论证

用于恰好两个可选方案，目标是比较它们最有力的理由，不是为偏好的选项找借口。输入是两个选项、目标和不可牺牲条件。

1. 用双方认同的表述定义 A、B，分别给最强论证、成立条件、收益与风险。不要把弱势方写成稻草人。
2. 统一时间尺度、成本口径和目标，指出真正分歧来自事实、预测、价值还是风险承受能力。
3. 找一个最可能改变推荐的问题，只问这一问并等待回答；不夹带第二套问卷，也不提前宣布最终选择。已给信息不重复索要。
4. 根据答案给条件明确的推荐、理由、代价和翻转条件；仍不确定就说明关键证据和最小取证方式。

输出双方最强版本、关键分歧、一个问题，以及回答后的推荐。若有三个及以上选项，请用户先选要深比的两项，或另设计实验；不能静默删除第三项。用户不愿缩小时可保留全体待选，说明本方法边界，不把二选一硬套多项排名。
