# Upstream Notice

This skill contains two GitHub PR helper components originally imported as community-contributed Apache-2.0 material in repository commit `fc890d7` and later adapted locally:

- `scripts/fetch_comments.py`
- `scripts/inspect_pr_checks.py`

Those components are distributed under the Apache License 2.0 in `LICENSE-upstream.txt`. They have been modified in this repository to integrate with `gh-pr-release`, correct PR repository resolution, and make check-analysis status and exit-code contracts explicit.
