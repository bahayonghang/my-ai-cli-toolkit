2. Take matching desktop and narrow screenshots from each project on initial load. Replay the corresponding exact request and CLI command from the run receipts, substituting fresh local paths. Compare the full tree and bytes with the original after each run.
3. Run `python measure.py <project>/comparison.html --channel msedge` and `python measure_proof.py <project> <external-output> --channel msedge --check-clear` from the associated fixture directories. The original proof desk must return 1 for both seeded defects. The valid control and directory must return 0. Run the chosen export’s `node scripts/slop_check.mjs <project> --design <project>/DESIGN.md --json` separately.
