# Mission: Rust Iterator Basics

## Why

Read an iterator pipeline in a small Rust CLI and explain when lazy evaluation begins.

## Success looks like

- Predict whether map runs before collect is called.
- Choose borrowed iteration when the original collection is needed later.

## Constraints

Ten minutes per lesson. This is a read-only test fixture for a skill probe.

## Out of scope

No project implementation, external accounts, or global agent memory updates.
