# Design

## Mechanisms
R1：以 playbook 的合取完成契约为准，修订 interview 的中英 draft/final 示例。扩充现有 ordinary published examples 测试的资源枚举，覆盖实际完整 Goal，不对访谈占位模板做误报。语义通过有代表性的断言与人工审阅核对，不新增生产正则词库。
R2：default strategy 撤销 legacy nested path 的写入承诺；只保留 writer 支持的根目录直接子文件策略。明确不把子目录伪装成新 repo-root 来绕过边界。
R3：root 负责 route → recon → choose/interview → compile/lint → present → authorized save/readback → stop。platform、persistence、review-remediation、Trellis 细节分别引用既有单一权威 reference；interface 的 default_prompt 缩成使用意图和权限边界，不再重复 root 全流程。
R4：保持 Governed 不变量；原 evals 更新或添加自然语言边界样例，全部是 recorded fixtures。更新现有 creation-handoff/prior-art/skill-ir 的当前变更说明与实际验证；不把格式校验称为 provider routing。父级 AGENTS 只删除 goal-meta 仍使用 expectations 的过时现状，不评价其他技能。

平台事实与 writer 不在此子任务写范围。版本只在本子任务最终整合时更新，使用下一适当版本且全部证据同步，不硬编码新版本作为需求。实现确认 linter 的 Generated by 断言和 persist-goal-contract.test.mjs fixture 含当前版本字面量；仅这两处元数据同步由原 lint implementer 独占处理，contract implementer 不并发编辑它们，不改变验证或写入行为。

实施时发现上述两个权威引用也包含当前版本/legacy 写入指示；主线程确认其最小同步属于既有 R2/R4，已纳入本文件列表，不扩展功能或写入能力。

## Retained capability matrix
| Capability | Authority after consolidation |
|---|---|
| draft/approved text, no activation | root + interface permissions |
| same-turn explicitly authorized save, create/replace/readback | root branch + persistent-goal-contract |
| platform selection and five renderers | root selector + platform-goal-facts |
| ordinary completion conjunction | playbook + interview examples |
| bounded material-only interview | interview-checklist |
| one-Prompt review remediation | conditional root link + review-remediation-contract |
| Trellis dispatch/opt-out/fallback/closeout | conditional root link + trellis-goal-cadence |
| evidence and provenance | existing reports |

## Trace and rollback
AC1 由示例同步和资源覆盖测试支撑；AC2 由文档收窄与 writer 既有测试支撑；AC3 由职责矩阵审阅和同口径字符对比支撑；AC4 由版本/报告对齐和仓库 CI 支撑。rollback 只回退本子任务，不能恢复首子任务已修复的 CLI。
