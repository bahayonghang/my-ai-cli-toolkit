# 上下文成本：基线与验收口径

## 本轮已测

`source-inventory.json` 对 26 份 `SKILL.md` 统一以 UTF-8 解码、CRLF→LF 计数；名称 / 描述通过当前环境 PyYAML 解析，hash 仍对应原始文件 bytes。这里不计宿主注入包装、文件路径与工具协议。

| 指标 | 当前值 | 含义 |
| --- | --- | --- |
| 可发现入口 | 26 | root 路由 + 25 叶子；5 项声明 disable-model-invocation |
| 全部名称 + description | 4,923 Unicode 字符 | 宿主若列出全部 metadata 的静态代理量 |
| 21 个模型可调用入口的名称 + description | 4,484 字符 | 按上游开关排除 5 项后的代理量；不是所有宿主的真实发现结果 |
| 路由完整 SKILL.md | 8,333 字符 | 含 frontmatter，LF 规范化 |
| 全部 26 份完整 SKILL.md | 80,771 字符 / 146,138 UTF-8 bytes | 说明全量拼接风险，**不是上游正常调用会全部加载** |

最初快速 regex 统计的 4,953 包含 YAML 折叠标记 / 缩进，不是字段值。本报告使用解析后的 4,923，不混用两种口径。本机标准 Python 未安装 tiktoken；本轮没有 tokenizer 证据，也没有真实客户端 token 数。

## 新包预算（规划目标，尚未验证）

1. 包内精确命名 `SKILL.md` 恰好一个。
2. YAML 解析后 `len(name) + len(description) ≤ 650`；相对两种已测 metadata 基线都减少至少 85%。这是字符代理量门禁，不是 token 百分比。
3. 根入口完整文本 ≤4,000 Unicode 字符且 ≤9,000 UTF-8 bytes。方法表直接定位 24 份方法；不再先读另一份大全索引。
4. 普通单方法请求首次只读取该方法，额外资源只在教学等明示依赖触发时读取。会话设置可与主方法共存；禁止默认预读所有方法、reports / evals。
5. 默认一轮一个主方法；用户明确要求或已有明确接力条件时最多两个不同主方法，长对话和新副作用必须分别通过进入条件。
6. 每个普通单方法路由场景的“新根 + 本次必读方法 / 资源”字符量不得高于“旧路由 + 相应叶子 / 同类必读资源”。旧 grill-me 计入其 grilling 转调。教学附录按完整依赖闭包另列，不能截断资源来制造节省。

预算是本包自己的设计约束。不能抄作模型或平台的官方限制；达不到时先瘦身和消除重复，不静默提高阈值。

## 必须同时报告三个场景

| 场景 | 旧版本 | 新版本 | 可说与不可说 |
| --- | --- | --- | --- |
| 整体安装后的发现 | 全 metadata，另列 model-eligible metadata | 单根 metadata | 可比较静态字符；客户端实际注入需新会话证据 |
| 经路由处理一个请求 | 旧路由 + 该叶子 + 实际必读依赖 | 新根 + 命中方法 + 实际必读依赖 | 同样的输入、同样文件口径；可作为主要节省目标 |
| 用户直接调用某个旧叶子 | 仅旧叶子及实际依赖 | 新根 + 内部方法及实际依赖 | 新包可能更重，必须如实记录，不选择性隐去 |

按需读取不会自动把已读文件从当前会话历史中清除。长对话 / 多方法使用的累积成本另列，不声称切换方法会回收上下文。

## 实施时的证据分层

- `tests/`：临时复制包并注入额外 SKILL、断链、失效别名或越预算根，确认检查会红；证明确定性结构合同，不证明模型遵循。
- `evals/evals.json`：行为规格，至少 25 项能力案例 + 12 个边界 / 回归案例。schema 通过不等于模型通过。
- `evals/trigger_cases.json`：至少 25 个正例（含每项能力的显式选择场景）、12 个纯负例、12 个近邻；显式入包和隐式发现分开标 family。qiaomu trigger_eval 是词项 smoke，不能拿它当模型行为质量评分。
- `reports/context-budget.json`：按固定 upstream commit、字符 / bytes 同口径报告，保存每方法明细和三个场景；token 字段无 tokenizer 时写 unavailable，不用字符/4 伪装实测。
- `reports/verification.md`：单方法 explain、歧义澄清、grilling、离线事实核查、教学 resume、任务书不激活、治理只预览、自我探索未请求这八类列 actual trace 或 `NOT_RUN`。记录实际读了什么、选择了什么方法、发了什么工具、是否有越权动作；预期文本不能当实际输出。
- 安装验证：把包复制到隔离临时目录，移除对 `ref/` 和作者本机的访问后仍能解析全部相对资源；这是 package isolation evidence，真实宿主 discovery 仍需另跑新会话。

新包没有落地前，上述结果统一为 planned / NOT_RUN；不得把规划中的门禁写成 PASS。
